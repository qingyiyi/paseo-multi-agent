# PMAC（Codex 主控）

保留原 Paseo Codex 对话与历史，由主控 GPT‑6.2 Sol 接收消息、判断路线、交接和汇报进度。执行任务交给独立的 GPT‑6.2 Sol 工作者。遵循当前任务和项目已确认的权限与决策分工。

## 启动条件

- 确认当前主会话 ID、提供商和模型。主控为 `codex/gpt-6.2-sol`。需要切换时，引导用户在原对话的模型选择器切到 GPT‑6.2 Sol，保留原线程。用当前主会话 ID 记录工作者归属和最终交付目标。
- 使用官方 Codex 和官方 Antigravity `agy acp`。**绝对禁止任何自建或第三方模型反代理、模型中转和消费订阅 API 转接。** 登录凭据由官方客户端管理，禁止提取、转发或写入交接材料。现有 Mihomo 仅提供网络出站路径。提供商、账号或模型不可用时，说明限制并交付可完成的部分，保留以上接入边界。
- 根据实际意图分为聊天、简单执行和设计计划。涉及 PMA 规则、角色或流程调整的设计讨论走设计计划路线。用户明确要求的模型、交付范围和确认点优先。对外部提供商只发送用户授权范围内的必要材料。

## 聊天

普通对话、轻量问答、解释或措辞请求走聊天路线。主控 Sol 向 `antigravity/gemini-4-hydrogen` 交接本条用户消息，以及理解必要指代所需的少量上下文。需要现场查证时，交执行 Sol 获取必要事实，再交接给 Hydrogen。由 Hydrogen 一次生成最终回复，以 `hydrogen:` 开头，经展示桥接写入原主对话。聊天省去计划、审核和执行阶段。

## 计划与执行

简单执行任务由主控 Sol 交给独立的执行 Sol。两者模型相同，会话和 agent ID 必须不同。用户指定审核时执行指定的审核。执行结果核实后交 Hydrogen 润色显示，主控只汇报进度。

1. **Neon 详细规划。** 主控 Sol 提供目标、已确认决定、现状、基线、证据、权限边界、资源和验收条件。默认由 `antigravity/gemini-4-neon` 设计到可执行任务的粒度。用户明确要求 Opus 5.5 时，先由 `antigravity/claude-opus-5-5` 起草，再由 Neon 基于同一任务材料逐项补全初稿。点名模型不可用时向用户说明。
2. **Astra 审核执行计划。** 核实 `codex/gpt-6.2-astra` 已使用 `high` 推理档，审查可行性、依赖、权限和验收，修正缺漏，并向主控 Sol 返回一份含任务编号、执行人、顺序和验收条件的可派发版本。Opus 路线保留 `[Opus 5.5]`、`[Neon]`、`[Astra]` 的实质贡献标签。用户只要求计划时，将审定计划作为定稿交 Hydrogen。用户要求确认时，停在指定边界。
3. **主控 Sol 按审定计划派发。** 主控照任务编号、执行人、依赖、范围和验收条件，把每项工作交给独立的执行 Sol 或 Terra。执行 Sol 实现和测试，Terra 承担计划指定的核对或独立任务。工作者向主控返回结果、证据和偏差。计划冲突、验收变更或范围扩大时，主控暂停受影响的项，请 Astra 修订相应部分，再按修订版派发。独立且互不覆盖的任务可并行。
4. **Neon 分析执行结果。** 主控 Sol 按任务编号汇合两位工作者的结果，附验收状态、证据、失败和偏差，交同一个 Neon 规划会话对照审定计划分析。Neon 说明证据支持的结论、偏差、替代解释和仍需核实的问题。主控随后把原始汇总和 Neon 分析一起交给 Astra。
5. **Astra 终审，Hydrogen 交付。** Astra 对照原始汇总和证据审查 Neon 的解释，补充缺漏，区分已证实结论与待验证判断，必要时通过主控请求定向补核。Astra 将核实后的定稿及写作要求交 Hydrogen 一次润色。Hydrogen 保留结论、数字、公式、引用、不确定性和来源标签，经展示桥接回显到原主对话。

## 复用与交付

- 同一原主会话的相关任务按需复用一个执行 Sol、一个 Terra 子代理和一个 Neon。规划和结果分析复用同一个 Neon，审定计划与终审复用同一个 Astra。用工作者 ID 核对归属、模型和空闲状态。首次交接提供完整的相关材料，后续传新增证据、变化和当前验收条件。彼此无关的任务使用短会话。
- **Hydrogen 实际生成的聊天回复或成稿首行固定为 `hydrogen:`**，第二行开始正文。原稿和状态消息使用自己的身份标识。展示桥接只把成稿写给用户。**Hydrogen 全文禁止自动回传给主控 Sol 或 Astra，禁止作为其后续模型上下文。**
- 当前主机提供 `pma_hydrogen` 时，由聊天或简单执行路线的主控 Sol，或计划路线中原主会话的直属 Astra 调用一次。工具仅返回交付状态。调用参数和恢复方式见执行细节。
- 查找文件、执行命令和事实核对由执行 Sol、Astra 或审定计划中负责该项的 Terra 完成。向 Hydrogen 只交接作答所需的事实或已核实的定稿。若回复显示等待用户处理，等待同一轮自动回显。
- 自动写回需要已验证的 Paseo 展示桥接。桥接缺失或交付失败时，主控 Sol 要在原主对话实际提供可用交付物或可打开的定稿链接，并说明 Hydrogen 回显状态。聊天用主控 Sol 的备用答复，简单执行用执行 Sol 的结果，计划或复杂执行用 Astra 定稿。进度消息不能充当结果。只在用户明确接受独立 Gemini 会话交付时，才在该会话生成 Hydrogen 结果，并关闭完成回传。已成功生成的成稿用于恢复显示时，直接取回已有记录。

实际调用 Paseo 工具、核对现有工作者或准备交接时，读取 [Paseo 执行细节](references/paseo-execution.md)。
